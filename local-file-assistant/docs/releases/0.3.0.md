# Local File Assistant 0.3.0 (OpenVINO build)

Installs from 0.2.0 update themselves: the app finds this version at its next daily check, downloads it in the
background and shows "Update 0.3.0 is ready" with RESTART NOW. Your index, chats, workspaces, settings and downloaded
models are kept, and the setup wizard doesn't come back.

## New

- **Setup wizard.** The first start walks you through it: the model engine (it comes with the installer), the model
  download with progress and a cancel button, access to your files, and a first question to try.
- **Workspaces.** Keep separate sets of documents, for example College and Office. A chat started in a workspace only
  answers from that workspace's folders.
- **FILES ONLY mode.** Chat checks each answer against your files. If it can't back an answer with a file, it says so
  instead of answering from general knowledge. A small model can still make a mistake, so open the source to be sure.
- **Drop a file into the chat.** Drag a PDF, document or photo onto the chat and ask about it. It is read for that
  answer only and not added to your index unless you choose to keep it.
- **Model picker.** Settings > Model lists the models on this PC with their size and how much memory they need, lets
  you download another, remove one you don't use, and choose whether the model runs on the graphics chip, the
  processor or the NPU. The app never switches to a bigger model by itself.
- **Plug-in tools.** Settings > Plug-in tools can add tool programs that run on this PC (MCP servers). The assistant
  can use them when your question asks for it. A tool that changes something or sends something always asks you first.

## Safety and privacy fixes

- If you use another model server (Settings > Model > another OpenAI-compatible server), it now only receives your
  questions, flashcards and the text of the files they use. It no longer receives your photos (image descriptions are
  made on this PC), your daily briefing, the list of file names the app picks from, or your plug-in tool list.
- A model server on another computer must use an encrypted (https://) address and needs a second confirmation.
- Plug-in tools whose names sound like they change things (delete, send, write, run...) now ask before running, even
  when the tool doesn't say so itself. You can mark a tool you trust as safe.
- Adding a plug-in tool program that hangs no longer freezes Settings or the chat.
- Workspaces find their own documents even when they are a small part of a big index, also for folder names with
  accents (for example "Ünal").
- Two workspaces can no longer have the same name.

## Updates

- The app checks once a day, and only reads this project's Releases page on GitHub. Nothing about you or your files
  is sent. Settings > General > Privacy turns it off completely.
- From this version on, an update is only installed when you click RESTART NOW. The app never restarts or installs by
  itself, also not when you quit it. (0.2.0 still installs this update when you quit it, as it always did.)
- Before the app upgrades its database of chats and settings, it keeps a copy of the old one next to it.
